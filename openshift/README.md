# `openshift/` — extra cluster files

YAML and notes that are useful on OpenShift but are not all applied through the GitOps `base/` overlay.

Includes namespace, network policy, TLS notes (`TLS_SETUP.md`), DDoS notes (`DDOS_PROTECTION.md`), backup/restore jobs, and an older standalone app Deployment. Day-to-day deploys use [`../gitops`](../gitops/README.md).
