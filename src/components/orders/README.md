# `orders/` — order UI

- `order-cards.tsx` — list of jobs as cards, including an open-dispute badge
- `seller-calendar.tsx` — month grid of booked visit slots, with Waze on the selected day
- `waze-navigate.tsx` — **נווט ב-Waze** deep link from street + city
- `deliver-dialog.tsx` — mark delivered with 1–6 photos and an optional note
- `delivery-photos.tsx` — private completion photos on the order page
- `dispute-dialog.tsx` — open a dispute with reason and photos
- `types.ts` — shapes shared by the orders page
