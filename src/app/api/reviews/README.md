# `reviews/`

Review actions on a review id. Averages for a daddy: gigs-service `GET /reviews/by-seller/:sellerId` (packages and local jobs, 1–10).

| Path | Methods | Purpose |
| --- | --- | --- |
| `/api/reviews/[id]/flag` | POST | Report a review |
| `/api/reviews/[id]/respond` | POST | Seller replies to a review (gig or local job) |
