# `requests/`

Local job requests (not a fixed gig).

| Path | Page |
| --- | --- |
| `/requests` | Open jobs for sellers (buyers see their own posts; guests see a public teaser) |
| `/requests/create` | Buyer describes a job, photos, street/floor, preferred window, and a visit slot |
| `/requests/[id]` | Request detail, seller quotes, side-by-side compare, accept quote |
