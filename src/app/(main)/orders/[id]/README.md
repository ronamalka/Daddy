# `[id]/`

The `/orders/:id` page. Buyer and seller manage one booking (status, visit time, chat, 1–10 review, dispute). Buyers cancel free until 24h before the slot; later a fee is recorded. After work starts the cancel control becomes “open a dispute”. Local jobs (`LOCAL_REQUEST`) can be reviewed the same way as packages. After a request is booked, the assigned daddy sees the visit street/floor and **נווט ב-Waze** (no live tracking). Marking delivered requires 1–6 completion photos (and an optional note) that only the buyer and seller see on this page.
