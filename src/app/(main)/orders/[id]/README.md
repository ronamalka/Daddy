# `[id]/`

The `/orders/:id` page. Buyer and seller manage one booking (status, visit time, chat, 1–10 review, dispute). Buyers cancel free until 24h before the slot; later a fee is recorded. After work starts the cancel control becomes “open a dispute”. Local jobs (`LOCAL_REQUEST`) can be reviewed the same way as packages. After a completed local job the buyer can start a standing schedule with the same daddy.
